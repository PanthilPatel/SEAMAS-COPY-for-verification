## Brand & Style

### Personality & Mission
The design system establishes a high-performance visual environment built for orchestration, observability, and confident commerce. It serves as an autonomous control center where complex multi-agent negotiations, price comparisons, and transaction executions are abstracted into transparent, real-time visual telemetry. 

The tone is:
- **Intelligent**: Computational clarity over decorative distraction. Information is structured to reduce cognitive load while providing total transparency into agent reasoning.
- **Fast**: High-frame-rate feel, near-zero visual inertia, and immediate micro-feedback during real-time streaming queries.
- **Trustworthy & Transparent**: Decisions, price-drop thresholds, and automated actions are traceable via visual breadcrumbs and inspection drawers.
- **Instrumented (Control Room)**: Inspired by telemetry dashboards and command consoles, blending sophisticated data density with consumer-ready polish.

### Design Movement: Tactical Glassmorphism & High-Density Minimal Telemetry
This system pairs ultra-refined glassmorphism with crisp, hairline architectural borders and precise monospaced accents. Backgrounds are deep, layered abyssal planes punctuated by high-luminosity reactive filaments: electric cyan for active data pipelines, magenta for system criticals and alternate states, emerald for confirmed financial yield, and indigo as the cohesive structural anchor.

## Colors

The system uses a dark-first foundation to maximize the luminous impact of real-time streaming vectors and agent telemetry.

### Dark Mode (Primary Palette)
- **Base Canvas**: `#070d19` (Deep void base).
- **Secondary Surface**: `#0a0a0f` (Inset panels, nested rails, terminal logs).
- **Elevated Glass Surface**: `#111827` rendered at `80%` opacity with a `16px` to `24px` backdrop blur (`rgba(17, 24, 39, 0.8)`).
- **Surface Borders**: Hairline `1px` stroke using `rgba(255, 255, 255, 0.08)`.
- **Primary Indigo Accent**: `#6366f1` (Primary interaction targets, confirmed execution paths).
- **Live Stream / Agent Telemetry (Cyan)**: `#5ad1ff` with `#8ff3ff` as high-contrast core (active agent queries, tokens streaming, scraping sweeps).
- **Critical / Secondary Agent Accent (Magenta)**: `#ff6be8` with `#c721a6` deep shade (agent collisions, budget limits, manual override alerts).
- **Value / Yield (Emerald)**: `#10b981` (Price drops, validated savings, cryptographic confirmation).
- **System Warning (Amber)**: `#f59e0b` (Stock velocity warnings, session timeouts).
- **Typography & Icons**:
  - Primary Content: `#f8fafc`
  - Secondary Telemetry: `#94a3b8`
  - Muted/Deactivated: `#475569`

### Light Mode Adaptations

## Typography

### Structural Role Alignment
1. **Space Grotesk**: Applied to high-level headers, metric displays, financial counts, and analytical card titles. It delivers a modern, mechanical precision that evokes autonomous computation.
2. **Inter**: Used across all continuous content, agent reasoning logs, product descriptions, tooltips, and standard interactive controls to ensure frictionless legibility.
3. **JetBrains Mono**: Dedicated to agent metadata, timestamps, latency metrics, hash identifiers, JSON inspectors, and live status tickers.

### Numerical Representation
- Indian Rupee (`₹`) indicators must be typeset using Space Grotesk alongside numerical figures, with `font-variant-numeric: tabular-nums` enforced across all dashboards to avoid vertical jitter during real-time value updates.
- Decimals in price values (e.g., `₹24,999.00`) should drop opacity to `70%` for the decimal fraction to emphasize the primary integer.

## Layout & Spacing

### Layout Structure
The interface implements a high-density, multi-pane control room structure using a 12-column responsive fluid grid on desktop and tablet, collapsing to a single-column operational view on mobile.

- **Desktop (1280px+)**: A tri-rail framework comprising:
  - Global Navigation & Session Inspector rail: Fixed 80px or collapsible 260px.
  - Autonomous Agent Operations Hub: Fluid center console (spanning 7-8 columns).
  - Telemetry, Live Stream & Cart Negotiation Ledger: 4-5 columns (minimum 380px).
- **Tablet (768px - 1279px)**: Dual pane layout. The secondary ledger collapses into an overlay slide-out activated by state-change triggers.
- **Mobile (<768px)**: Unified vertical stack prioritizing real-time shopping execution with sticky bottom-anchored agent status overlays.

### Rhythmic Discipline
All spatial intervals follow a strict 4px/8px modular base. Dense component clusters (such as live agent query chips, micro-meters, and table data) use `space-xs` (4px) and `space-sm` (8px), whereas hero surfaces and card modules leverage `space-lg` (24px) to preserve clarity in dark environments.

## Elevation & Depth

Visual hierarchy is constructed through ambient luminance, translucent glass stacking, and hairline vector containment rather than structural drop shadows.

### Elevation Architecture
1. **Level 0 (Canvas Void)**: `#070d19` flat background. Non-interactive base.
2. **Level 1 (Recessed/Secondary Surface)**: `#0a0a0f` with `0.5px` border `rgba(255, 255, 255, 0.04)`. Used for agent terminal histories, logs, and inactive slot containers.
3. **Level 2 (Glass Floating Surfaces & Cards)**: Base `#111827` with `80%` opacity (`rgba(17, 24, 39, 0.8)`), backdrop-filter blur `16px`, hairline border `1px solid rgba(255, 255, 255, 0.08)`. Subtle top-lit highlight via internal box-shadow: `inset 0 1px 0 0 rgba(255, 255, 255, 0.06)`.
4. **Level 3 (Interactive Floating Panels, Dropdowns, Drawers)**: `#111827` at `92%` opacity with backdrop blur `24px`. Border: `1px solid rgba(255, 255, 255, 0.12)`. Ambient shadow: `0 16px 40px -12px rgba(0, 0, 0, 0.6)`.
5. **Level 4 (Agent Signal Overlay / Active Focus)**: Dynamic glow wrappers using accent colors:
   - Live stream mode: `box-shadow: 0 0 24px -4px rgba(90, 209, 255, 0.25)`.
   - Alert / Critical intervention: `box-shadow: 0 0 24px -4px rgba(255, 107, 232, 0.25)`.

## Shapes

The interface balances sharp, technical command-center geometry with ergonomic readability through a tiered radius system:

- **Micro Controls & Chips (`rounded-base`)**: `8px` (`0.5rem`). Applied to buttons, inputs, badge indicators, dropdown items, and agent pill tags.
- **Card Containers (`rounded-lg`)**: `14px` to `16px` (`1rem`). Applied to product comparison cards, negotiation pods, agent reasoning modules, and graph boards.
- **Master Stage & Hero Panels (`rounded-xl`)**: `24px` (`1.5rem`). Applied to outer viewport modules, multi-agent conversational canvases, and primary checkout review chambers.
- **Terminal Pill**: Fully rounded (`9999px`) reserved strictly for live state indicators (e.g., pulsing active dots, streaming badges).

## Components

### Buttons & Interactive Triggers
- **Primary Command**: `#6366f1` solid background with `#ffffff` text, Space Grotesk 14px SemiBold. State transitions trigger an internal radial glow overlay. Hover: `#4f46e5` with `0 0 16px rgba(99, 102, 241, 0.4)`. Radius: `8px`. Height: 40px.
- **Agent Action (Telemetry Cyan)**: Ghost surface (`rgba(90, 209, 255, 0.08)`), text `#5ad1ff`, border `1px solid rgba(90, 209, 255, 0.3)`. Hover: background `rgba(90, 209, 255, 0.16)`.
- **Critical Action (Magenta)**: Surface `rgba(255, 107, 232, 0.1)`, text `#ff6be8`, border `1px solid rgba(255, 107, 232, 0.3)`. Used for manual overrides or rejecting an agent's proposed deal.

### Agent Status Badges & Chips
- Embedded JetBrains Mono 10px uppercase indicators.
- **Streaming State**: Cyan border `rgba(90, 209, 255, 0.3)`, dark translucent fill `rgba(7, 13, 25, 0.8)`, accompanied by a pulsing 6px radial dot alternating between `#5ad1ff` and `#8ff3ff`.
- **Savings Chip**: Emerald surface `rgba(16, 185, 129, 0.12)`, text `#10b981`, showing delta calculation (e.g., `↓ ₹2,450.00`).

### Cards & Container Modules
- Constructed with `14px` radius, `#111827` at `80%` opacity, `16px` backdrop-filter blur, and `1px` border `rgba(255, 255, 255, 0.08)`.
- **Negotiation Card**: Features an integrated dual-split header with agent handle (cyan), target item, current best bid formatted in Space Grotesk `₹` metric, and an interactive log inspector accordioned at the footer.

### Input Fields & Command Omnibar
- **Universal Agent Omnibar**: 52px height, 12px radius, dark surface `#0a0a0f` at `90%` opacity with hairline border `rgba(99, 102, 241, 0.3)`. Focus shifts border to `#5ad1ff` and applies an ambient outer glow `0 0 16px rgba(90, 209, 255, 0.2)`. Space Grotesk placeholder text with JetBrains Mono keyboard shortcut indicators (`⌘K`) right-aligned.
- **Standard Inputs**: 40px height, 8px radius, `rgba(17, 24, 39, 0.6)` background, Inter 14px body text, hairline border `rgba(255, 255, 255, 0.1)`.

### Selection Controls (Checkboxes & Radios)
- Custom square (`6px` radius) or circle controls. Hairline border `rgba(255, 255, 255, 0.2)`.
- Checked state: `#6366f1` background with white glyph, emitting a subtle local bloom (`box-shadow: 0 0 8px rgba(99, 102, 241, 0.5)`).

### Multi-Agent Telemetry Stream (Specialized Component)
- A specialized continuous-feed console component utilizing monospace JetBrains Mono 12px.
- Features alternating token timestamps, agent color tags (`Agent-01::PriceScraper` in `#5ad1ff`, `Agent-02::DealNegotiator` in `#ff6be8`), and automated typewriter stream animations with auto-scroll lock toggles.
